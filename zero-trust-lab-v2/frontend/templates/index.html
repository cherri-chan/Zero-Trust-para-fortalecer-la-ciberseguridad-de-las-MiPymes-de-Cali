Arquitectura conceptual

Vista simplificada del flujo del laboratorio

01 · IdentidadUsuario activo, rol y MFA habilitado.
02 · DispositivoAsociación, autorización, estado y postura.
03 · PolíticaReglas activas para identidad, dispositivo, rol y segmento.
04 · RecursoSensibilidad, segmento protegido y rol requerido.
05 · DecisiónPERMITIDO o DENEGADO con motivo trazable.
06 · AuditoríaRegistro de usuario, dispositivo, recurso, política y tiempo.
07 · PersistenciaSQLite local para datos simulados y eventos.
08 · InterfazDashboard web para observación y demostración.
Usuario / Dispositivo → Identidad + MFA → Postura del dispositivo → Rol / Recurso → Segmento → Política → Decisión → Auditoría
Alcance: la segmentación se representa lógicamente dentro de la aplicación. El laboratorio no pretende sustituir una infraestructura empresarial de red, IAM o SIEM.
